# UX Copy Guide

Preferred product language:

- monitor
- setup
- strategy map
- condition
- alert
- proof
- detected
- forming
- confirmed
- unavailable
- ambiguous
- provider-required

Avoid:

- guaranteed
- profitable
- buy now
- sell now
- best trade
- high probability unless quoted from the user and marked as ambiguous
- will catch pumps

Builder copy principles:

- Explain what was understood before showing the board.
- Never imply TraceEdge predicts future price movement.
- Make unsupported conditions explicit.
- Use “Start Monitoring”, not “Start Trading”.
- Use “proof” and “condition evidence”, not “signal certainty”.
