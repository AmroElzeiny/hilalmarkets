{#- A coin's picture, for every server-rendered surface in the product. One definition. The markup was written out six times — the Screened Market, the Passport, the activity list, the home page, the Opportunities cards and the redesigned dashboard popups — and each copy decided for itself which of the coin's pictures it was willing to ask for. Three of them wrapped *both* attributes in `{% if logo_module_url %}`, so a coin with a stored picture but no catalogue entry lost the one picture it had. Two more built the catalogue address out of a version number typed into the template. Which pictures exist is not decided here, and is never decided in a template. It is `core/asset_logos.py`, reached through the `asset_logo` global, which answers with: `image_url` the picture stored on the coin's own record when a reviewer verified its identity. `provider_url` the market-data provider's picture, gathered by the coin researcher. Exists for far more coins than the catalogue covers, and is often the only picture a small or newly listed token has. `module_url` the shared icon catalogue, addressed by ticker. `monogram` the letters to show until one of those has actually loaded. A caller that already holds a resolved record passes both addresses in; a caller holding only a ticker passes neither and gets the same answer. Each address is written only if it exists, and they are written independently, because having one and not the other is the normal case rather than an edge case. The letters are not a failure state: they are what a coin with no picture anywhere is supposed to look like, and `static/asset-logos.js` only replaces them once a real picture has actually loaded. `decorative` hides the whole thing from a screen reader. Pass it wherever the coin's name or symbol is already written beside the picture: hearing "B T C" and then "BTC/USDT" is noise, not information. It is not the default only because a surface that does *not* state the symbol nearby would then say nothing at all about which coin it is showing. -#} {%- macro coin_logo(symbol, module_url=none, image_url=none, provider_url=none, class='', element='span', decorative=false) -%} {%- set resolved = asset_logo(symbol) -%} {%- set module = module_url or resolved.module_url -%} {%- set image = image_url or resolved.image_url -%} {%- set provider = provider_url or resolved.provider_url -%} <{{ element }} class="{{ class }}" data-asset-logo-symbol="{{ resolved.ticker or (symbol|string|upper) }}"{% if module %} data-asset-logo-module="{{ module }}"{% endif %}{% if image %} data-asset-logo-url="{{ image }}"{% endif %}{% if provider and provider != image %} data-asset-logo-provider-url="{{ provider }}"{% endif %}{% if decorative %} aria-hidden="true"{% endif %}>{{ resolved.monogram }} {%- endmacro -%} {#- The same thing where the surrounding markup needs a `
