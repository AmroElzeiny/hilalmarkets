{#- The Ask AI button. One producer. Every surface that wants a button calls this macro, so the markup, the accessible name, and the gate all live in one place and cannot drift apart. The macro must be imported `with context` because it reaches for `hilal_chat` and `settings` to decide whether the assistant is on. When the gate is off, nothing is rendered — there is no disabled button and no dead control. On a public page, where Hilal never runs, it opens the public assistant when that one is on. The visible label is always "Ask AI". The accessible name is passed by the caller and must start with those words (WCAG 2.5.3). The button is not a toggle: it opens the assistant window and never closes it, so it carries `aria-haspopup` and `aria-controls` but not `aria-expanded`. -#} {%- macro ask_ai(name, topic=none, compact=false) -%} {%- if hilal_chat_gate(hilal_chat|default(false), settings) -%} {%- elif public_chat_enabled|default(false) -%} {#- A public page has no Hilal. The same button opens the public assistant, which is the one a visitor without an account can use. -#} {%- endif -%} {%- endmacro -%}
