# Telegram And Discord Actions

## Alert Actions

Confirmed and forming alert presentations can include:

- View Full Proof
- Open Chart
- Good Alert
- Too Early
- Too Late
- False Alert
- Open Replay
- Missed Move Review
- Improve Monitor
- Mute Monitor
- Open Dashboard

Deep analysis opens the dashboard. Telegram and Discord remain compact review surfaces.

## Feedback

Feedback callback identifiers include the alert UUID and are ownership-validated before
storage. Feedback is linked to the alert, setup instance, monitor version, source channel,
and audit event.

Repeated feedback may create a safe suggestion draft. It never changes a live monitor.

## Temporary Mute

Mute Monitor stores a 24-hour version-specific mute timestamp. The notification preference
service enforces it across delivery channels while preserving scans and evidence.

## Discord Components

Discord component interactions support feedback and temporary monitor mute actions. Link
buttons open proof, replay, missed-move, improvement, or dashboard pages.

## Safety Copy

Channel messages continue to state that TraceEdge is monitoring and decision support. They
do not use guaranteed-profit, risk-free, buy-now, or sell-now language.
