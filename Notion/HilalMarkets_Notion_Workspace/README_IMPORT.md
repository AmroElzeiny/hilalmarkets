# 📥 Importing this workspace into Notion

## Recommended method

1. Download and unzip `HilalMarkets_Notion_Workspace.zip`.
2. In Notion, open **Settings → Import → Markdown & CSV**.
3. Import the complete unzipped folder.
4. Markdown files become pages; CSV files can become Notion databases.
5. Keep the `assets` folder with the Markdown pages during import so images and the animated GIF remain available.

## Suggested Notion structure

- Make **🏠 HilalMarkets HQ** the workspace home.
- Place pages 01–20 beneath the home page.
- Import each CSV in `databases/` as a full-page database.
- Place `templates/` beneath a “Templates” page.
- Add the supplied cover PNG to the workspace home and use the GIF in product demos.

## Evidence labels used

- **Implemented:** present in the current public repository.
- **Operationally gated:** software exists, but production configuration, governance, licensing, or human approval is still required.
- **Planned:** a strategic next step, not represented as current functionality.
- **Hypothesis:** requires user, market, or commercial validation.

## Maintenance

Update the workspace whenever one of these changes:
- methodology or reviewer governance;
- product navigation or customer terminology;
- plan prices or limits;
- production provider and deployment status;
- accelerator deadlines or terms;
- private-beta metrics;
- legal or regulatory advice;
- material competitor positioning.
