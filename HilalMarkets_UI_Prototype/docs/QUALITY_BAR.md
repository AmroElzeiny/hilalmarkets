# Quality Bar

The requested scores are treated as a design target, not an objectively guaranteed measurement.

Every primary page was built against these review dimensions:

| Dimension | Target |
|---|---|
| HilalMarkets identity | Sharia screening is visible in hierarchy, copy, status, and workflow—not only color |
| Modernity | Contemporary asymmetry, strong whitespace, original bento structures, restrained motion |
| User flow | Each page has one clear primary job and next action |
| Beginner usability | Intent-first language, progressive disclosure, visible explanations |
| Trust | Methodology, version, review date, and evidence context stay close to decisions |
| Human-designed feel | Original composition, custom icon set, deliberate copy, no generic AI gradient/template pattern |
| Competitive originality | The design does not reproduce any reviewed competitor page structure |
| Responsiveness | Desktop, tablet, mobile, and reduced-motion behavior included |
| Handoff readiness | Named route placeholders, reusable component guide, and FastAPI/Jinja migration plan |

## Page-specific acceptance checklist

- [ ] The first viewport explains the page’s purpose.
- [ ] Sharia context is visible where relevant.
- [ ] One primary action has clear visual priority.
- [ ] Advanced complexity is not the default.
- [ ] Empty, loading, error, and stale-data states are defined during implementation.
- [ ] Icons support labels rather than replace them.
- [ ] Status colors retain a single semantic meaning.
- [ ] Motion explains an update rather than decorating a static screen.
- [ ] Mobile keeps status, key evidence, and primary action above the fold.
