# Public Page Decisions

## What belongs in the landing header

Keep the header short and task-oriented:

1. Features
2. How It Works
3. How We Screen
4. Pricing
5. Help Center
6. Sign in
7. Start free

This gives a new visitor five answers:
- What does it do?
- How does it work?
- Can I trust the screening?
- What does it cost?
- Where can I get help?

## What should not be in the landing header

Keep these in the footer:
- About
- Contact
- Trust & Safety
- Risk Disclosure
- Privacy
- Terms
- Cookie Policy
- Cookie Settings

They matter, but they are not primary evaluation tasks for most first-time visitors.

## Why each separate page exists

| Page | Reason |
|---|---|
| Features | Prevent the landing page from becoming a full product manual |
| How It Works | Explain the user journey without mixing it with technical capability lists |
| How We Screen | Central authoritative explanation for Sharia methodology, evidence, governance, and disagreement |
| Pricing | Give plans, limits, comparison, billing questions, and one backend source of truth |
| Help Center | Separate operational questions from purchase FAQs |
| Contact | Route support, governance, partnership, privacy, media, and security inquiries |
| About | Explain mission, audience, values, and market direction |
| Trust & Safety | Join security, privacy, market-data integrity, governance, and user control |
| Risk Disclosure | Make monitoring, crypto, data, alert, and screening limitations visible |
| Privacy | Explain personal-data handling and analytics boundaries |
| Terms | Define service, accounts, billing, acceptable use, and availability |
| Cookie Policy | Explain categories, consent, Google Consent Mode, and preference changes |

## Pages not needed initially

### Separate FAQ page

Do not create one yet:
- keep four purchase-critical questions on the landing page;
- put operational questions in the Help Center;
- use contextual explanations inside the dashboard.

### Public community or creator page

Delay until the creator/community product is operational and supported by real demand.

### Public portfolio page

Delay until holdings workflows, privacy, market data, and compliance monitoring are production-ready.

## Cookie experience

Do not force-open the Cookie Policy page on first visit.

Show a first-visit consent banner with:
- Essential only
- Customize
- Accept analytics

Keep Cookie Policy and Cookie Settings in the footer. Optional analytics remains denied until the user chooses.
