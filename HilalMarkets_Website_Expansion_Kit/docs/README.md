# HilalMarkets Website Expansion Kit

This package extends the original HilalMarkets UI prototype with:

- an updated landing page;
- dedicated public Features, How It Works, How We Screen, Pricing, Help Center, Contact, About, Trust & Safety, Risk Disclosure, Privacy, Terms, and Cookie Policy pages;
- a functional first-visit cookie banner and preference center;
- Google Consent Mode v2 defaults and update logic;
- original local SVG illustrations;
- data-driven local SVG graphs;
- a current-system comparison;
- a compact detailed Codex alignment prompt;
- public navigation, sitemap, and robots references;
- the previous complete dashboard and activation page library.

## Run locally

```bash
cd HilalMarkets_Website_Expansion_Kit
python serve.py
```

Open:

```text
http://127.0.0.1:8080/preview.html
```

## Start with these files

## Important

- All production links remain `#TODO_*` placeholders.
- `data-preview-href` exists only for local browsing.
- Charts contain illustrative product data, not production traction or trading performance.
- SVG illustrations are original local assets, not competitor copies.
- Legal pages are structured drafts requiring qualified review.
- The package does not present sample methodology or asset data as a real Sharia determination.
- The custom cookie banner is an implementation reference and does not replace legal analysis or a certified CMP where required.
