# UX and Content Guide

## Primary persona

The guided active Muslim investor:
- beginner to mid-level,
- uses or considers crypto spot,
- wants values alignment and personal control,
- understands basic market behavior but may not understand formulas,
- wants evidence rather than anonymous signals.

## Core vocabulary

| Avoid as default | Use |
|---|---|
| Strategy | Watch Plan |
| Candidate | Opportunity |
| Partial match | Forming |
| Near miss | Getting closer |
| Conditions complete | Ready for review |
| Lifecycle | Opportunity journey |
| Blocker | What is still missing |
| Universe | Screened market |
| Halal score | Status, methodology, reason, and evidence |
| AI decided | Screened under an approved methodology |

## Required status wording

Prefer:
> Screened as eligible under HM-01, version 1.4, reviewed 8 July 2026.

Avoid:
> Definitely halal.

## Every opportunity card should answer

1. What asset is this?
2. What is its current Sharia status?
3. Which methodology and date support that status?
4. What market behavior is forming?
5. How ready is it?
6. What is present?
7. What is still missing?
8. What can the user do next?

## Empty states

Empty states should explain the reason and next action. Do not show unexplained zeros.

## Errors

Every error must include:
- what failed,
- whether other monitoring continues,
- whether evidence is stale,
- what the user can do,
- a stable reference for support.

## Disclosures

Keep “research and monitoring only,” “no execution,” and methodology-specific status wording visible without overwhelming the main action.
