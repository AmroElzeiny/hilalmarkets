How cookies, local storage, consent, and Google tag settings should work on HilalMarkets.

Draft for counsel review · 15 July 2026
What cookies areCategoriesConsentGoogle tagsManage choicesChanges
The first visit should show a banner, not force-open this page. The banner provides Essential only, Customize, and Accept analytics choices. This page remains available from the footer.

What cookies and similar storage are

Cookies, local storage, and related technologies can remember security state, preferences, consent, and limited website activity. Some are necessary to provide the service; others require a choice.

Categories used by this design

Essential

Authentication, security, load balancing, fraud prevention, consent storage, requested settings, and core application behavior. These cannot be switched off through the preference center where they are required to provide the service.

Analytics

Optional measurement of public-page and product use to understand activation, reliability, and usability. Analytics should be configured to avoid private Watch Plan text, credentials, reviewer notes, support attachments, and direct identifiers.

Functional

Optional remembered preferences that are not strictly required, such as public-site personalization.

Marketing

Advertising measurement or personalization. It is disabled by default in this prototype and must not be activated without explicit consent, legal review, and production configuration.

Consent choices

On the first public visit, HilalMarkets should set optional consent states to denied before loading Google tag configuration. The banner then updates those states after the user chooses. The choice is stored with a version and timestamp.

Google Consent Mode

The code kit initializes Consent Mode v2 states for ad storage, analytics storage, ad user data, ad personalization, functionality storage, personalization storage, and security storage. Google Consent Mode is a technical signaling layer, not the user-facing banner itself.

Manage or withdraw choices

Use the button below or the Cookie Settings link in the footer. Withdrawal should affect future optional processing; it may not remove legally required records or information already processed under another lawful basis.

Changes to this policy

Material changes should update the policy date and, where necessary, request consent again by increasing the stored consent version.
