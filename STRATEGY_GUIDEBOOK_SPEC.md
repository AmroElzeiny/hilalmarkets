# Strategy Guidebook Spec

The Strategy Guidebook is the user-facing condition catalogue.

It exposes these categories:

- Popular
- Price
- Indicator
- Price Action
- Market Structure
- Liquidity / Smart Money
- Candle Pattern
- Volume / Flow
- Volatility / Squeeze
- Trend
- Momentum
- Time / Session
- Market Context
- Risk / Trade Quality
- Alert Behavior
- Advanced Logic

Each condition card must show:

- Readable name.
- One-line explanation.
- Example sentence.
- Required data.
- Beginner/advanced badge.
- Plan availability.
- Provider requirement.
- Preview sentence.
- Add button only when executable.

Unsupported and provider-required capabilities must be visible as unavailable, not presented as fully executable.
