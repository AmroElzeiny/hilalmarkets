# Telegram UX

Telegram is the fast assistant surface.

Main menu:

- Quick Scan
- Create Monitor
- My Monitors
- Near-Miss Radar
- Setup Replay
- Latest Alerts
- Trial
- Subscription
- Settings
- Support
- About

Guidelines:

- Keep messages compact.
- Show processing feedback before slow operations.
- Use dashboard links for dense evidence, chart replay, billing, and advanced editing.
- Keep old aliases working when possible.
- Go Back should move to the parent screen, then home.
- Alert actions should lead to useful proof, replay, settings, or feedback states.
- Support should direct the user to the configured contact instead of collecting repeated technical data in chat.

Risk language:

Telegram must say the product monitors and supports decisions. It must not imply guaranteed results.
