# Design System

## Visual principles

1. **Evidence-led, not decorative.**
2. **Financial technology first; Islamic identity expressed with restraint and product truth.**
3. **Beginner-first hierarchy with optional advanced detail.**
4. **Status color is semantic, never ornamental.**
5. **Animation explains state change.**

## Palette

| Token | Value | Use |
|---|---:|---|
| Emerald 950 | `#082F29` | dark surfaces |
| Emerald 800 | `#0F5C4D` | primary identity and action |
| Emerald 600 | `#1F8B74` | progress and eligible status |
| Warm ivory | `#F7F4EC` | public background |
| Ink | `#15231F` | text |
| Restrained gold | `#D2AF63` | methodology, evidence, emphasis |
| Amber | `#B87820` | qualification and review |
| Red | `#B94A4A` | exclusion and critical issue |

## Typography

- Display: Manrope
- Body: DM Sans
- Fallbacks are included.
- Do not use condensed trading-terminal typography as the primary product language.

## Radius and spacing

- Small radius: 12px
- Card radius: 20px
- Hero/major panel radius: 28–34px
- Main spacing follows an 8px rhythm.

## Iconography

`assets/js/icons.js` contains an original line-icon set. Icons are used to support scanning, not replace labels. Desktop navigation always includes icon plus text.

## Motion

- Interface transitions: 150–250ms.
- Meaningful state changes: 300–700ms.
- No constant pulsing.
- Orbit animation is limited to public hero and market-check illustration.
- `prefers-reduced-motion` disables nonessential animation.

## Logo

The logo combines:
- a restrained crescent,
- ascending market bars,
- an evidence/market trajectory.

Avoid mosque silhouettes, decorative calligraphy, or generic Islamic pattern overload.
