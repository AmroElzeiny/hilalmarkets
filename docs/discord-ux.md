# Discord UX

Discord supports personal alerts, community servers, support, and creator plans.

Recommended slash commands:

- /create_monitor
- /monitors
- /near_miss
- /setup_replay
- /latest_setups
- /alerts
- /proof
- /subscription
- /settings
- /support
- /dashboard

Design rules:

- Complex setup creation should open a secure dashboard link.
- Server alerts may use setup threads so lifecycle updates stay grouped.
- Paid roles follow verified billing entitlements, not slash-command claims.
- Moderation must flag scam links, impersonation, malicious files, seed phrase requests, and guaranteed-profit claims.
- Alert embeds must show the same deterministic evidence as Telegram and dashboard.
