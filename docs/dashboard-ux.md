# Dashboard UX

The dashboard is the advanced control surface.

Navigation:

- Overview
- Quick Scan
- Monitors
- Strategy Builder
- Setup Replay
- Near-Miss Radar
- Alerts & Proof
- Latest Setups
- Analytics
- Historical Replay
- Exports
- Billing
- Integrations
- Settings
- Support
- Referrals
- Admin

Overview should show:

- Active monitors.
- Alerts today.
- Near-misses today.
- Latest setup.
- Latest alert.
- Market Coverage Score.
- Telegram connection.
- In-app and Telegram connection state.
- Quick actions.

Style:

Modern dark trading interface, dense but readable, with clear warning and error colors. Avoid casino-like hype.
