# Provenance and Publication Rules

1. External status is immutable source evidence.
2. AI cannot write into external status, authority, meeting, decision date or source reasoning.
3. Canonical asset identity requires human verification; ticker-only matching is forbidden.
4. Every source row starts as `PENDING_ADMIN_REVIEW`.
5. Approval must record admin, date, reason, source snapshot and canonical asset.
6. Rejection stores the record and removes it from customer universes; it does not delete it.
7. Missing evidence means unpublished/insufficient information, not non-compliant.
8. A result from one methodology cannot be copied into another methodology.
9. Comparison displays independent opinions; no averaging or majority score.
10. Native asset, staking, lending, yield, wrapped versions and derivatives are separate product/use layers.
11. Migrated and duplicate symbols must remain separate until canonical identity review.
12. Public passports must visibly separate external authority information from HilalMarkets factual enrichment.
