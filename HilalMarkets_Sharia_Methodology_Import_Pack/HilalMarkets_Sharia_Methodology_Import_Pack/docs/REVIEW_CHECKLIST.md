# Admin Review Checklist

Before approving any source row:

- Confirm the source page still shows the same status.
- Confirm asset name, symbol, chain and contract/native identity.
- Confirm migration or duplicate-symbol handling.
- Confirm methodology attribution and scope.
- Confirm current assessment date/status history.
- Confirm rights state allows intended display.
- Review all official-source AI enrichment.
- Verify decisive facts manually.
- Confirm missing or contradictory evidence is visible.
- Confirm third-party lending, yield, staking and derivatives are not silently included.
- Confirm the Passport separates external and HilalMarkets sections.
- Record the decision reason and evidence snapshot.
